# Best of Rick Roll

A collection of over-engineered rickrolls. Each folder is one contributor's rickroll: the page, the server config that serves it, and a README explaining the tricks it pulls.

## Contributing

Everyone is invited to contribute. Got a rickroll you're proud of? Add it:

1. Fork the repo.
2. Create a folder named after you (your GitHub handle works), e.g. `yourname/`.
3. Put your page in it, plus whatever it needs to run (server config, assets, setup scripts).
4. Add a `README.md` in your folder explaining what your rickroll does and how to deploy it.
5. Open a pull request.

Improvements to someone else's rickroll are welcome too, as are ideas in the issues.

Keep it a prank: the punchline is Rick Astley. No malware, no collecting credentials or personal data, nothing that harms the visitor's device.
